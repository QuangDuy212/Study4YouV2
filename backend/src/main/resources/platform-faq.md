# Study4You Platform FAQ & Features

## What is Study4You?
Study4You is a professional TOEIC learning platform. It allows students to take practice tests, learn grammar, and track progress. Admins can manage users and content.

## Key Features
- **Practice Tests**: Full or part-based TOEIC tests.
- **AI Generation**: Automatically generate practice questions using Gemini.
- **Dashboard & Analytics**: Track scores and study time.
- **Admin Panel**: Manage tests, parts, questions, and users.

## Role Types
- **STUDENT**: Can take tests and view progress.
- **TEACHER**: Can manage tests and questions.
- **ADMIN**: Full control over the platform.
